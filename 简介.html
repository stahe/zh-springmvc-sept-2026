    1.1. Spring MVC 在 Web 应用程序中的作用

    Web 应用程序通常按层构建，每一层只与相邻的层通信：

    • Web 层接收来自浏览器的 HTTP 请求，并向其返回 HTML 页面。[Spring MVC] 帮助我们编写这一层；
    • 业务层包含应用程序的业务规则（例如“一位患者只能有一个即将到来的预约”）。它对 Web 一无所知：它同样可以为命令行应用程序提供服务；
    • 数据访问层（[DAO] 层，即 [Data Access Object]）负责读写数据库。我们将使用 [Spring Data JPA]，它依赖 ORM [Hibernate]（[Object Relational Mapper]）将表中的行与 [Java] 中的对象相互映射。

    Web 层本身遵循 [MVC] （[Model – View – Controller]）模型：

    • 控制器（C）是一个类，其方法称为 动作，每个动作处理一种特定类型的请求（例如 [GET /schedule]）。动作读取请求参数，调用业务层，然后选择要显示的视图；
    • 模型（M）是动作传递给视图的数据集合；
    • 视图（V）是一个 [Thymeleaf] 文件（扩展名为 [.html]）：这是一个 HTML 页面，其中某些标签带有 [th:...] 属性（[th:text]、[th:each]……），[Thymeleaf] 引擎会用模型中的数据替换这些属性。

    请求的处理过程遵循图中的编号步骤：

    • 1：浏览器发送一个 HTTP 请求，例如 [GET /schedule?doctorId=1&day=2026-09-24]；
    • 2：由 [Tomcat] Web 服务器（由 [Spring Boot] 嵌入应用程序中）接收请求。请求先经过一系列 过滤器 （读取 Cookie、身份验证等），然后到达 [DispatcherServlet]，它是 [Spring MVC] 的唯一入口，负责选择处理该请求的动作：这就是 路由。在到达动作之前，请求还可能经过 拦截器，我们将在后面的章节中探讨；
    • 3：动作向业务层请求所需的数据；必要时，业务层会联系 [DAO] 层，由该层用 SQL 查询 [MySQL] 数据库；
    • 4：动作构建视图模型 M，并指定应显示该模型的视图；
    • 5：视图引擎 [Thymeleaf] 生成页面 HTML，[Spring MVC] 再将其返回给浏览器。

    [Spring] 是全球使用最广泛的企业应用开发框架（[Java]） 。它免费开源，凡是 [Java] （[Windows]、[Linux]、[macOS]）能运行的地方都能运行。[Spring MVC] 是其中的 Web 组件；[Spring Boot] 是一个上层封装，它根据项目中存在的库自动配置整套环境（Web 服务器、JSON 转换、视图引擎、数据访问等），并把应用程序变成一个标准的 [Java] 程序，由 [main] 方法启动。[Spring MVC] 既可以创建向 [JavaScript] 客户端（[Angular]、[React]、[Flutter]……）返回 JSON 的服务器，也可以创建传统的 Web 应用程序，即由服务器生成 HTML 页面，浏览器只负责显示。本文档聚焦于后一种用法。与 [ASP.NET Core] 一样，[Spring] 基于两个理念：注解 （[@GetMapping]、[@RequestMapping]、[@PreAuthorize]……）描述类和方法的角色，而 依赖注入 为每个对象提供其所需的依赖。[Spring] 事实上正是推广了第二个理念的框架之一。

    1.2. 所用工具

    这些示例使用以下工具编写和测试（安装方法见附录）：

    • [JDK] 21（[Java Development Kit]），其中包含 [javac] 编译器和 [java] 虚拟机。[Java] 21 是一个 LTS（长期支持）版本；
    • [Maven] 3.9.11 构建工具，无需安装：每个项目都包含一个 Maven Wrapper （脚本 [mvnw] 和 [mvnw.cmd]），首次使用时会自动下载正确版本的 [Maven] ；
    • [Visual Studio Code] 编辑器，以及 [Extension Pack for Java] 和 [Spring Boot Extension Pack] 扩展；
    • 一款较新的浏览器（[Chrome]、[Firefox]、[Edge]）；
    • 命令行工具 [curl]，用于显示原始的 HTTP 响应（[Windows] 10 和 11 已自带）；
    • 数据库管理系统 [MySQL] （或 [MariaDB]），例如 [Laragon] 在 [Windows] 下附带的那个，从数据访问一章开始使用，并用于案例研究。

    与包含 [.NET] 的 SDK（其中带有 [ASP.NET Core]）不同，[JDK] 并不包含 [Spring]：该框架是一组库，由 [Maven] 在首次编译时从中央仓库 [Maven Central] 下载（因此那一天必须连接互联网），然后存放在本地文件夹中（用户主目录下的 [.m2] ）。这些库被归并为 starter：一个 starter 就是一个依赖，它提供某项特定功能所需的一切。所有示例都使用 [spring-boot-starter-webmvc] （[Spring MVC] 和服务器 [Tomcat]）；此外还有 [spring-boot-starter-validation] （数据验证，从第 3 章开始）、[spring-boot-starter-thymeleaf] （视图，从第 4 章开始）、[spring-boot-starter-security-oauth2-resource-server] （[Spring Security] 和 JWT 令牌，第 8 章）、[spring-boot-starter-data-jpa] 以及 [mysql-connector-j] 驱动（数据库访问，第 9 章）。所用版本为 [Spring Boot] 4.1.1 所对应的版本：[Spring Framework] 7.0.9、[Spring Security] 7.1.1、[Hibernate] 7.4.5、[Thymeleaf] 3.1.5、[Jackson] 3（JSON 转换）以及 [Tomcat] 11。
