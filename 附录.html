    13. 附录

    13.1. 安装 JDK 21

    [JDK] （[Java Development Kit]）包含 [javac] 编译器和 [java] 虚拟机。有若干免费的发行版可供选择；我们使用来自 [Eclipse Temurin] 的 [Adoptium] 项目，可从 adoptium.net 下载：选择版本 21（LTS），然后选择适合你系统的安装程序（[Windows] x64、[macOS]、[Linux]）。

    在 [Windows] 中，[.msi] 安装程序在自定义界面上提供了“Set JAVA_HOME variable”选项；该选项默认是禁用的——你必须启用它。环境变量 [JAVA_HOME] 指定 [JDK] 的位置；Maven Wrapper 用它来定位 [Java]。你也可以使用 [winget] 包管理器：

    1
    winget install EclipseAdoptium.Temurin.21.JDK

    对于 [macOS]，请使用同一页面上的 [.pkg] 安装程序，或者使用包管理器 [Homebrew] （[brew install --cask temurin@21]）。对于 [Linux] （例如 [Ubuntu]），发行版仓库中的 [openjdk-21-jdk] 包就很合适：

    1
    sudo apt install openjdk-21-jdk

    在新的控制台（[PowerShell]、命令提示符或终端）中验证安装：

    1
    java -version

    它应显示以 21 开头的版本号（例如 [openjdk version "21.0.10"]）。更新的 [JDK] （例如 25）同样可用；更旧的 [JDK] （例如 17）在编译时会产生错误 [release version 21 not supported]。

    13.2. Maven 与 Maven Wrapper

    无需安装任何东西：[examples] 文件夹和案例研究文件夹各自都包含 Maven Wrapper，即 [mvnw] 脚本（[Linux]、[macOS]）和 [mvnw.cmd]（[Windows]），以及文件 [.mvn/wrapper/maven-wrapper.properties]，其中指定了要使用的 [Maven] 版本（3.9.11）。首次运行时，脚本会下载该版本的 [Maven] 并将其存放在用户的主目录中（[.m2/wrapper] 文件夹）；之后的运行会重复使用它。[Maven] 则从 Maven Central 仓库下载项目的库，并将它们存放在 [.m2/repository] 文件夹中。因此，首次编译期间需要连接 Internet。

    Maven Wrapper 需要 [Java]：它使用由变量 [JDK] [JAVA_HOME] 指定的 JDK，或者在没有该变量时，使用路径（[java] [PATH]）中找到的命令 java。要验证一切就绪，请编译 [examples] 文件夹中的所有示例：

    1
    ./mvnw compile

    （在 [.\mvnw compile] [Windows] 下使用 .\mvnw compile）。该命令以 [BUILD SUCCESS] 结束。

    如果你更愿意自己安装 [Maven] （maven.apache.org），则在文档中的所有命令里，命令 [mvn] 都替代 [mvnw] 。

    13.3. 安装 Visual Studio Code

    从 [Visual Studio Code] 下载 code.visualstudio.com。添加两个扩展（进入“查看”菜单 > 扩展，然后搜索其名称）：

    • [Extension Pack for Java]，来自 Microsoft：一组扩展，为 [Java] 代码提供语法高亮、代码补全和错误报告；支持 [Maven] 项目（Java Projects 窗格）；调试器，以及每个保存文件的自动编译；
    • [Spring Boot Extension Pack]，来自 VMware（marketplace.visualstudio.com）：为 [application.properties] 提供属性自动补全、在 Bean 与 URL 控制器之间导航，以及 Spring Boot Dashboard 窗格，该窗格列出已打开文件夹中的 [Spring Boot] 应用，并允许你单击一下即可启动或停止每一个应用。

    打开 [examples] 文件夹或案例研究文件夹（“文件”菜单 / 打开文件夹）；集成终端（“终端”菜单 / 新建终端）让你无需离开编辑器即可运行 [mvnw] 命令。在应用的启动类（名为 [@SpringBootApplication] 的那个类）中按 F5 键，会在调试器的控制下运行该应用。

    13.4. 使用 Laragon 安装 MySQL

    [Laragon] （laragon.org）会安装一个可直接使用的 [MySQL] 服务器（或 [MariaDB]），以及 [HeidiSQL] 管理工具。安装之后：

    • “Start All”按钮会在端口 3306 上启动 [MySQL] 服务器；
    • 用户 [root] 没有密码：这些是示例 28 和案例研究中 [spring.datasource.*] 属性的默认值；
    • “Database”按钮会打开 [HeidiSQL]，其中的“文件”菜单 / 运行 SQL 文件菜单项可运行脚本 [dbpersons.sql] （示例 28）和 [dbrdvmedecins2.sql] （案例研究）。

    在 [Linux] 或 [macOS] 中，使用系统的包管理器安装 [MySQL] 或 [MariaDB] ，并使用命令行客户端 [mysql] 运行这些脚本。来自 [JDBC] 的 [MySQL] 驱动程序无需任何配置也可用于 [MariaDB] ：[Hibernate] 只会在启动时显示 [HHH000511] 警告，不会有任何后果（参见示例 28）。

    13.5. 安装 curl

    [curl] 已包含在 [Windows] 10 和 11、[macOS]、以及大多数 [Linux] 发行版中。在 [PowerShell] 中，你必须输入 [curl.exe]，而不是 [curl]：在较旧版本的 [PowerShell] 中，[curl] 是另一个命令（[Invoke-WebRequest]）的别名，而该命令的选项不同。
